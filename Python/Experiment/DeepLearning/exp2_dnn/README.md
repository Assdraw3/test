# 实验二：深度网络优化（超参数与正则化消融）

## 环境依赖
见 requirements.txt

## 运行
python exp2.py

## 说明
- 基于实验一相同网络结构（参数量 235,146）
- 共 27 组实验，分 7 个系列（A~G），通过修改配置项切换
- 对比优化器、学习率调度、Dropout、权重衰减、早停、组合正则、极端学习率
- 每组跑 20 epoch（早停组除外），以验证集精度最优保存模型
- 测试集仅用于最终评估，不参与调参

## 关键发现
- StepLR / Cosine 调度效果最好，测试精度最高 89.47%
- Dropout=0.2 有效抑制过拟合（差值从 6% 降至 3.5%）
- 早停 patience=3 过于激进，建议 ≥5
- lr≥1 导致梯度爆炸，精度退化为随机猜测

## 输出
- 每组日志：终端输出
- 汇总结果：results/summary.csv
- 曲线图：outputs/figures/（由实验者自行生成插入报告）
